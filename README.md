# 😎 Чёткий Ярославль — бесплатный новостной бот ВКонтакте

Отдельный проект для [группы ВК «Чёткий Ярославль»](https://vk.ru/club243223029). **Не использует OpenAI API, внешние платные сервисы или платный ИИ.** Автомобильный репозиторий не затрагивается.

## Что делает
- До **30 постов в сутки** — по одному в каждом 48-минутном слоте по московскому времени. GitHub Actions запускается каждые 5 минут (с возможными задержками).
- Использует две проверенные в тестовом запуске RSS-подборки Google Новости по Ярославлю; недоступный RSS «Городского телеканала» отключён после тайм-аута. Публикует только заголовки не старше 36 часов и с явной городской привязкой.
- Без ИИ: локальный Python-шаблонизатор добавляет сленговое обращение и эмодзи, **не выдумывая фактов**. Полное смысловое перефразирование и глубокая проверка фактов без ИИ недоступны.
- Формат: **одно предложение + ровно 3 тематических хэштега**, привязанных к Ярославлю. Учитывает историю хэштегов и придумывает новые комбинации.
- Не повторяет URL, проверяет сходство заголовков, хранит историю опубликованных и пропущенных ссылок в `history.json`.
- **30 — предел, а не гарантия**: если подходящих неповторяющихся городских новостей недостаточно, пропускает слот.

## Настройка
Нужен **только один секрет GitHub** в [Settings → Secrets and variables → Actions](https://github.com/76kovka76-hub/chetkiy-yaroslavl-vk/settings/secrets/actions):

- `YAROSLAVL_VK_TOKEN` — **токен сообщества ВК 243223029** с правами для публикации `wall.post`.

ID группы **243223029 уже указан в `main.py`**, отдельный `VK_GROUP_ID` не нужен. **`YAROSLAVL_OPENAI_KEY` не нужен**, и даже если он был создан ранее, скрипт его не читает. Не передавайте ключи в чат и не добавляйте их в код.

Для сохранения истории: GitHub → Settings → Actions → General → Workflow permissions → **Read and write permissions**. [Прямая ссылка](https://github.com/76kovka76-hub/chetkiy-yaroslavl-vk/settings/actions).

## Статус: автопубликация включена
- В [workflow](https://github.com/76kovka76-hub/chetkiy-yaroslavl-vk/blob/main/.github/workflows/publish.yml) установлено `DRY_RUN: "false"`: новые запуски могут **публиковать реальные записи в VK**.
- Запуск по расписанию каждые ~5 минут, но не более одного поста в 48-минутный слот и 30 в московские сутки.
- `Run workflow` также запускает **реальный постинг**, если подошло время и есть новая новость. Используйте осторожно.
- [Логи GitHub Actions](https://github.com/76kovka76-hub/chetkiy-yaroslavl-vk/actions/workflows/publish.yml) показывают `Опубликовано: <post_id>` после успешной отправки.
- [История публикаций](https://github.com/76kovka76-hub/chetkiy-yaroslavl-vk/blob/main/history.json) хранит отправленные сообщения и ссылки.
- Чтобы временно остановить постинг, поменяйте `DRY_RUN: "false"` обратно на `DRY_RUN: "true"` или отключите workflow в GitHub Actions.
- **Запуск №14** проверил 10 тестов и создал корректный пробный текст; **право токена ВК на публикацию проверится только при первой реальной отправке**.

## Ограничения бесплатной версии
- Без ИИ это короткая **шаблонная подача реального заголовка**, а не свободный пересказ от человека.
- Фильтр одинаковых ссылок строгий, похожих заголовков приблизительный. Одинаковое событие под очень разными заголовками иногда может пройти.
- Наличие Ярославля в заголовке не гарантирует, что новость касается именно города. Источники и достоверность нужно сначала проверить тестовыми запусками.
- Бесплатные источники RSS могут менять адреса, становиться недоступными и требовать настройки. В запуске №14 два фида Google Новости вернули по 100 материалов, а третий местный фид был исключён из-за тайм-аута.
- GitHub Actions в **публичном репозитории со стандартными раннерами бесплатно** по действующим условиям GitHub. При переводе репозитория в приватный или выборе платного раннера условия и лимиты меняются.
- Публикуются только тексты, без чужих фотографий.
